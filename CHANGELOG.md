# ForeverUtils v2026.48.4

Tooltips on Target Finder's world map pins, and a way to remove them.

## New

- **Tooltips on map pins.** Hover a pin on the world map to see which mob it's for, its coordinates and how many spawn points are shown.
- **Remove pins from the map.** Shift-click a pin to remove it, for example once you've checked that spot. Shift-right-click any pin to remove them all. Clicking the mob's map button in the `/tf` window brings them back.
